# 🏥 Hospital Management System

## 📌 Project Description

The Hospital Management System is a console-based Java application developed to manage basic hospital activities.

This project helps manage patient details, doctor information, and appointment bookings using Java programming concepts.

## 🚀 Features

- Add Patient Details
- Add Doctor Details
- Book Appointments
- View Patient Details
- View Doctor Details
- Search Patient by ID
- View Appointment Details
- Exit the Application

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Eclipse IDE

## 📚 Java Concepts Used

- Classes and Objects
- Constructors
- Methods
- Encapsulation basics
- ArrayList
- For-each Loop
- Conditional Statements
- Switch Case
- Scanner Class

## ▶️ How to Run the Project

1. Install JDK on your computer.
2. Open Eclipse IDE.
3. Create a Java Project.
4. Create a package named `sugunam`.
5. Create a class named `Hospital`.
6. Copy the Java source code.
7. Run the program.
